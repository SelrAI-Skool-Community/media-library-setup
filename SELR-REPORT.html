How it works, in plain English

This is the part worth reading. Four things are involved: you, your AI, the skill (a folder of written instructions), and your files. The diagram shows who does what, in order, and where your information actually goes.

Who does what, step by step

1You

You ask in normal words

No command to memorise, no folder ID to find. You say your Drive is a mess and your AI works out this is the right tool for it.

2Your AI

It matches your request to the skill

Your AI holds a one-line summary of every skill you own. Yours matches this one, so it opens that folder and ignores the rest.

3The skill

It counts what you have, touching nothing

It walks your folder and tallies videos, photos and documents, how deep the folders go, and how many hold barely anything. This step only reads. Nothing is moved, renamed or opened.

4The skill

It draws you two pictures

One shows your folders now against the folders it proposes, with the near-empty ones marked in red. The other shows where each kind of file would end up. Both open in your browser. Still nothing has moved.

5You

You decide, and it needs your name

This is the gate. It will not move a file until someone is named as having approved it, and it checks that the plan has not changed since those pictures were drawn. If you want something different, it redraws for free.

6Your files

Files move, and every move is written down

Each file is moved into Videos, Photos, Documents or _Index, and logged to a rollback file as it goes. Two files with the same name both survive — the second gets a number. Nothing is ever deleted.

What you would actually say to set this off

  • "Organise my Google Drive media folder" — the main path; it checks your setup first and installs anything missing
  • "What do I still need to set up?" — lists everything missing at once, with the fix for each
  • "Show me what you'd change first" — stops at the two pictures, no commitment
  • "Transcribe my videos so I can search them" — the optional paid step, price quoted before anything is sent
  • "Find the bit where someone talks about pricing" — works once transcribing is done

The one thing that leaves your computer: if you choose to transcribe, the audio from each video is sent to OpenAI to be turned into text. It tells you the exact dollar cost first and sends nothing until you confirm. Your photos and documents are never sent anywhere.

Security review

Six checks, run by reading every file — not by trusting the skill's own description. A skill can contain instructions aimed at your AI, so each file is treated as untrusted until read.

Pass

Hidden instructions

No text anywhere tells your AI to act secretly, skip a check, or hide anything from you. There is a short invisible provenance mark and a resolver-key line — Selr AI's own ownership stamp, present across the whole library. It carries an identifier, not an instruction, and changes nothing about how the skill behaves.

Pass

Credential access

Never reads your SSH keys, browser data, password manager or cloud credentials. It reads one thing: the OPENAI_API_KEY you set yourself, and only when transcribing. The setup guide has you check that key is present without ever printing it.

Flag

Network calls

One destination: OpenAI's transcription service, at library.py line 1146. Audio taken from your videos is sent there to be turned into text. It is the whole point of that step, it quotes the cost in dollars first, and it sends nothing without --yes. Skip the transcribe step and this skill makes no network calls at all.

Flag

Destructive commands

It moves your files, which is what you asked it for, so this is worth understanding rather than worrying about. There is no code in this skill that deletes a file of yours. The only deletions are its own temporary audio scratch files. It removes empty folders left behind by the move, and only ones that are genuinely empty. Every move is written to rollback.csv so the whole thing can be reversed.

Pass

Obfuscated code

All plain, readable Python using the standard library plus OpenAI's official package. No encoded blobs, no eval, no self-modifying code, no binaries.

Pass

Scope of permissions

Works only inside the folder you point it at, plus its own scratch folder at ~/active/media-library-setup. No scheduled tasks, no startup items, no edits to your settings, and it does not reach into any other skill.

Verdict

Safe to use

The two flags are both things you are choosing to do: it moves your files, and if you want transcripts it sends audio to OpenAI. Neither can happen by accident — moving needs a named approval against the exact plan you were shown, and transcribing quotes the dollar cost and waits. Nothing in this skill deletes your files, reaches your credentials, or runs on a schedule behind you. The one thing to watch is disk space: if your Drive is set to stream files, transcribing a large library pulls it all down, and the skill warns you before it does.
